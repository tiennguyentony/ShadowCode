# Label images

Put the three Tilemark label images here, named by Product_ID:

- `1001.png`
- `1002.png`
- `1003.png`

Each is the `label.png` made in `/training` (195.072 dpi, 7.68 px per mm, label 114 x 149 mm). Tony copies them here; Kiro does not copy anything out of `/training`.

`../labels.html` sizes each image in millimetres, so the pixel size of the file does not change the printed size. A missing file is printed as a 114 x 149 mm outline with its Product_ID.
